# Approved Examples

Use this file to record approved repo-native example references.

Commands and skills should consult this file when repo-specific patterns matter.
This is especially important for planning, implementation, review, and grilling skills that would otherwise guess local style.

Recommended format:

- `{path}` - UI pattern
- `{path}` - service or business-logic pattern
- `{path}` - test pattern
- `{path}` - state, data-flow, or workflow pattern

Do not copy large code blocks here. Prefer paths plus short reasons.
