# Promote Pattern

## Objective

Turn an approved repeated pattern into durable AI-layer behavior.

## Required Behavior

- read the approved candidate
- confirm the intended target type
- update the relevant `.ai/` file or folder
- record what changed and why
- save an approval artifact

## Promotion Targets

- `.ai/commands/`
- `.ai/skills/`
- `.ai/AGENT.md`
- `.ai/templates/`
- `.ai/context/`
- `.ai/project.yaml`

## Output

- `.ai/evolution/approved/{slug}.approved.md`
