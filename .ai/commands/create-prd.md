# Create PRD

## Objective

Create a reviewable PRD that reduces ambiguity before planning.

## Required Behavior

- Start with `grill-me`.
- Challenge missing success criteria, scope boundaries, edge cases, and non-goals.
- Save the result using the PRD template.
- Keep the PRD grounded in repo and workflow reality rather than generic product language.
